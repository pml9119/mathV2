## 二、学情分析

1. **知识基础**：学生已掌握椭圆、双曲线、抛物线的定义与标准方程；已学空间向量、线面垂直/平行判定、线面角与二面角的定义。
2. **现有短板**：
   - 解析几何：对“定义转化”不敏感（题 1 的 |PA|−|PF₂| 不会联想椭圆定义）；对“动圆相切”的外切/内切半径关系容易混淆；对“斜率定值→定点”的韦达消参不熟练；
   - 立体几何：截面问题缺乏“动点→截面形状演化”的空间想象力；四点共面证明不会建向量桥接；空间角求法对“设动点参数”感到困难。
3. **可借力点**：高二学生已具备函数、向量基础，对“图随讲解动”的直观演示接受度高；动图+分步讲解能显著降低抽象门槛。

## 三、教学目标（三维）

### 知识与技能
1. 能利用**椭圆定义**将线段差的表达式转化为线段和差的最值问题（题 1）；
2. 能由**圆与圆的位置关系**（外切 |PM|=r+1、内切 |PN|=9−r）确定动点轨迹（题 2）；
3. 能运用**设线-联立-韦达-消参**研究斜率关系，求直线恒过定点（题 3）；
4. 能借助**截面与侧面平行/比例关系**判断截面形状随动点变化的临界（题 4）；
5. 能综合运用**共面判定（向量共面/平行线）**与**空间角（线面角）转化为法向量夹角**求解（题 5）。

### 过程与方法
1. 经历“审题转化 → 数形结合 → 代数运算 → 回代验证”的解题流程，体会解析几何“几何关系代数化、代数结果几何化”的思想；
2. 通过动图演示，在“图随讲解动”中建立动点、截面、临界位置的直观想象；
3. 通过一题多解（题 5 向量法与平行线法），体会证明方法的多元路径。

### 情感态度与价值观
1. 感受数学中“动中有静、静中有动”的辩证关系，增强学习兴趣；
2. 在分步讲清、动手探索中建立“难题也可拆解”的信心，克服对压轴题的畏难情绪；
3. 培养严谨规范书写、一题多解反思的良好习惯。

## 四、教学重点与难点

### 教学重点
1. **椭圆定义的转化应用**：|PF₁|+|PF₂|=2a 在最值、轨迹、定点问题中的核心地位；
2. **动圆相切问题的轨迹方程**：外切/内切半径关系的正确表达；
3. **截面临界分析**：找出“截面由四边形变为五边形”的临界位置；
4. **空间角（线面角）的建系求解流程**：建系 → 坐标 → 法向量 → 夹角公式。

### 教学难点
1. 题 1：把 |PA|−|PF₂| 利用定义改写为 |PA|+|PF₁|−2a，再用三角不等式取等条件（三点共线）；
2. 题 2：|PM|·|PN| 的二次函数换元与取值范围；
3. 题 3：设线 x=my+n 后，从 k_PA=2k_QB 化出关于 n 的方程并**排除 n=−2**（过 A 不合题意）；
4. 题 4：动点 M 连续变化时，截面形状的“临界”分析；
5. 题 5：第（2）问中**动点 F 的参数化**（PF=t·PB）与法向量夹角方程求解，以及 PF/BF 的双解讨论。

## 六、教学过程（45 分钟）

### 环节一 导入（约 3 分钟）
- 多媒体出示封面：六道期中真题，来自河北石家庄、重庆、上海等名校；“一题一屏、动图讲透”。
- 提问：回顾椭圆定义？动圆相切半径关系？线面角定义？
- 目标：激活旧知，明确本课“从真题出发、用定义与建系两大武器”。

### 环节二 题 1 精讲（约 7 分钟）
**题目**：已知 F₂ 为椭圆 mx²+y²=4m（0<m<1）的右焦点，A(0,2)，点 P 为椭圆上任意一点，且 |PA|−|PF₂| 的最小值为 −4/3，则 m=（ ）。

**步骤/讲解**：
1. **审题转化**：椭圆 mx²+y²=4m → 化为标准式 x²/4 + y²/(4m) = 1，则 a²=4、b²=4m、c²=4−4m；左焦点 F₁(−2√(1−m),0)。
2. **定义改写**：由定义 |PF₁|+|PF₂|=2a=4，得 |PA|−|PF₂| = |PA|+|PF₁|−4。
3. **三角不等式**：|PA|+|PF₁| ≥ |AF₁|（等号当 A、P、F₁ 共线且 P 在 A、F₁ 之间时取到）。
4. **计算**：|AF₁| = √((0−(−2√(1−m)))²+(2−0)²) = √(4(1−m)+4) = √(8−4m)。
5. **列方程**：√(8−4m)−4 = −4/3 → √(8−4m) = 8/3 → 8−4m = 64/9 → m=2/9。
6. **验证**：0<m<1 ✓，选 **D**。

**动图联动**：图形显示椭圆、左焦点 F₁、点 A(0,2) 在椭圆外；动点 P 绕椭圆运动，显示 |PA|、|PF₁|、|PF₂| 实时读数；学生观察 |PA|+|PF₁| 何时最小（与 A、F₁ 共线）。

**设计意图**：用“定义+三角不等式”处理线段差最值，是解析几何最值的第一基本招式。

### 环节三 题 2 精讲（约 9 分钟）
**题目**：动圆 P 与圆 M:(x+3)²+y²=1 外切，与圆 N:(x−3)²+y²=81 内切。（1）求动圆圆心 P 的轨迹方程；（2）求 1/|PM|+1/|PN| 的取值范围。

**步骤/讲解**：
1. **审题转化**：圆 M 圆心 M(−3,0)、半径 r₁=1；圆 N 圆心 N(3,0)、半径 r₂=9；圆心距 |MN|=6<r₂−r₁=8，两圆内含。
2. **外切/内切半径关系**：动圆 P 半径 r，外切 |PM|=r+1，内切 |PN|=9−r。
3. **定义**：|PM|+|PN|=(r+1)+(9−r)=10>|MN|=6 → P 的轨迹是以 M、N 为焦点的椭圆，a=5,c=3,b=4 → **x²/25+y²/16=1**。
4. **第（2）问转化**：用参数化 P(x,y)，x∈[−5,5]；由椭圆焦半径：|PM|=5+3x/5，|PN|=5−3x/5。
5. **换元**：设 t=|PM|∈[2,8]，则 |PM|·|PN| = t(10−t) = −t²+10t，在 t∈[2,8] 上 ∈ **[16,25]**。
6. **结论**：1/|PM|+1/|PN| = (|PM|+|PN|)/(|PM|·|PN|) = 10/(t(10−t)) ∈ **[2/5, 5/8]**。

**动图联动**：显示圆 M、圆 N、动圆 P；动点 P 绕椭圆运动，实时读出 |PM|、|PN|、1/|PM|+1/|PN| 的数值；学生观察 |PM|+|PN| 恒等于 10，1/|PM|+1/|PN| 在 [2/5, 5/8] 内变化。

**设计意图**：①圆锥曲线定义（轨迹）；②“二次函数+换元”求范围——动点最值范围的典型做法。

### 环节四 题 3 精讲（约 8 分钟）
**题目**：椭圆 E: x²/4+y²/2=1，A、B 是左右顶点，P、Q 在椭圆上，满足 k_PA=2k_QB，则直线 PQ 恒过定点（ ）。

**步骤/讲解**：
1. **审题转化**：A(−2,0)、B(2,0)；设 P(x₁,y₁)、Q(x₂,y₂)，且 y²=(4−x²)/2。
2. **斜率**：k_PA=y₁/(x₁+2)，k_QB=y₂/(x₂−2)。
3. **先看 P·B 两个斜率**：P(x₁,y₁) 在椭圆上，x₁²/4+y₁²/2=1 → y₁²=(4−x₁²)/2，故 k_PA·k_PB = y₁/(x₁+2) · y₁/(x₁−2) = y₁²/(x₁²−4) = ((4−x₁²)/2)/(x₁²−4) = −1/2（与 0≤x₁ 无关，P 取任意点恒成立）。这是椭圆的对称斜率性质。
4. **设线**：直线 PQ: x=my+n（斜率存在情况），代入得 (m²+2)y²+2mny+n²−4=0；Δ=8(2m²−n²+4)>0。
5. **韦达**：y₁+y₂ = −2mn/(m²+2)，y₁y₂ = (n²−4)/(m²+2)。
6. **k 条件代入**：由 k_PA=2k_QB → y₁/(x₁+2) = 2·y₂/(x₂−2) → 整理得 (m²+1)y₁y₂ + m(n+2)(y₁+y₂) + (n+2)² = 0。
7. **消参求解**：代入韦达 → (m²+1)(n²−4)/(m²+2) + m(n+2)·(−2mn)/(m²+2) + (n+2)² = 0 → 3n²+8n+4=0 → n = −2/3 或 n = −2。
8. **检验**：n=−2 时直线 x=my−2 恒过 A(−2,0)，而 P、Q 均在椭圆上且 k_PA 有意义 → 舍去；故 n=−2/3，直线恒过 **T(−2/3,0)**，选 **C**。

**动图联动**：椭圆上动点 P，直线 PT 交椭圆于 Q；学生拖动 P，观察 P、Q 与定点 T 共线，且 k_PA=2k_QB 恒成立，体会“动中有定点”。

**设计意图**：①斜率定值定点问题——“设线-联立-韦达-消参-检验”完整流程；②增强代数运算规范与“检验舍根”意识。

### 环节五 题 4 精讲（约 8 分钟）
**题目**：正方体 ABCD−A₁B₁C₁D₁ 体积为 1，M 在线段 BC 上（≠B,C），N 在 CC₁ 上且 CN=1/3，若平面 AMN 截正方体所得截面为四边形，则 BM 取值范围为（ ）。

**步骤/讲解**：
1. **审题转化**：正方体棱长 1；M 在 BC 上：BM=t，B 为端点；N 在 CC₁ 上：CN=1/3。
2. **截面法（延展法）**：平面 AMN 与各棱相交；因面 ADD₁A₁ ∥ 面 BCC₁B₁，平面 AMN 与这两平行面的交线（面 ADD₁A₁ 内的 AD₁ 与面 BCC₁B₁ 内的 MN）互相平行 → **MN ∥ AD₁ ∥ BC₁**。
3. **临界**：由 MN ∥ BC₁（BC₁ 方向 (0,1,1)）→ 在侧面 BCC₁B₁ 中 CM=CN=1/3 → BM=1−CM=1−1/3=**2/3**。
4. **分情况**：
   - 当 0<BM≤2/3 时，截面 AMN 只交 4 个面（顶点 A、M、N、交 A₁D₁ 上的点），截面为四边形；
   - 当 BM>2/3 时，平面 AMN 还与面 ABB₁A₁ 相交出额外交点，截面为**五边形**。
5. **结论**：**BM∈(0, 2/3]**，选 **D**。

**动图联动**：立方体；M 沿 BC 滑动，显示截面（四边形→五边形）连续性变化；学生拖动 M 观察“临界”位置（过顶点 D₁ 时）。

**设计意图**：①截面作图与“平行面截线平行”性质；②动点连续变化下的临界分析，是立体几何选择压轴的高频模型。

### 环节六 题 5 精讲（约 9 分钟）
**题目**：四棱锥 P−ABCD，△PBC 为等边三角形，底面 ABCD 是矩形，平面 PBC⊥平面 ABCD，O、E 分别为线段 BC、PA 的中点，点 F 在线段 PB 上（不含端点）。（1）若 PF=(2/3)PB，求证 O、D、E、F 四点共面；（2）若 BC=2AB=2，是否存在点 F，使 EF 与平面 PCD 所成角的正弦值为 √39/13，若存在求 PF/BF，若不存在说明理由。

**步骤/讲解**：
1. **审题转化**：矩形 ABCD + △PBC 等边（BC=2 时，PB=PC=2，高 √3）；O 为 BC 中点，PO⊥BC，又面 PBC⊥面 ABCD → **PO⊥面 ABCD**。
2. **（1）向量法（共面判定）**：取 O 为原点，x 轴沿 BO 方向，y 轴沿 OD 方向，z 轴沿 OP 方向（标准正交系）：O(0,0,0)，B(−1,0,0)，C(1,0,0)，D(1,1,0)，A(−1,1,0)，P(0,0,√3)，E(−1/2,1/2,√3/2)。
   因为 PF = (2/3)PB → F = P + (2/3)(B−P) = P + (2/3)(−1,0,−√3) = (−2/3, 0, √3/3)。
   共面判定法一（同基向量表出）：以 O 为基准，OF = (−2/3,0,√3/3)，OE = (−1/2,1/2,√3/2)，OD = (1,1,0)。
   解 OF = a·OE + b·OD：z: a·√3/2 = √3/3 → a = 2/3；y: a/2 + b = 1/3 + b = 0 → b = −1/3；x: (−1/2)·(2/3) + (−1/3)·1 = −1/3 − 1/3 = −2/3 ✓。
   三式同时成立 → **OF = (2/3)OE − (1/3)OD**，即 F 在平面 ODE 内 → **O、D、E、F 四点共面**。
   共面判定法二（纯向量，原题解路径）：以 P 为基点，记 b = PB、c = PC、d = PD、a = PA。O 为 BC 中点 → PO = (b+c)/2；E 为 PA 中点 → PE = a/2；底面 ABCD 为矩形 → a = b + d − c。
   要证 F 在平面 ODE 内，只需找到 λ、μ、ν 满足 PF = λ·PO + μ·PD + ν·PE 且 λ+μ+ν = 1（仿射组合判定）。
   代入：PF = (2/3)b = λ·(b+c)/2 + μ·d + ν·(b+d−c)/2。
   按 b、c、d 不共面比较系数：
   b：λ/2 + ν/2 = 2/3；c：λ/2 − ν/2 = 0 → λ = ν；d：μ + ν/2 = 0。
   解得 ν = λ = 2/3，μ = −1/3，且 λ+μ+ν = 2/3 − 1/3 + 2/3 = 1 ✓
   ∴ PF = (2/3)PO − (1/3)PD + (2/3)PE（系数和 = 1）→ **O、D、E、F 四点共面**。
   **说明**：四点共面判定要点：取一个基准点（如 O），证明第四个点的向量 = 前三个点向量的线性组合（系数可任意，不必和为 1；和为 1 是“四点共面且基准在外”的另一种表述，与矩阵秩一致）。
3. **（2）建系求解**：取 O 为原点，x 轴沿 BO 方向，y 轴沿 OD 方向，z 轴沿 OP 方向（标准正交系）：O(0,0,0)，B(−1,0,0)，C(1,0,0)，D(1,1,0)，A(−1,1,0)，P(0,0,√3)。
   设 F 在 PB 上：令 PF = t·PB（0<t<1），则 F = P + t(B−P) = (−t, 0, √3(1−t))。E 为 PA 中点：E(−1/2,1/2,√3/2)。
   于是 EF = F−E = (1/2−t, −1/2, √3/2−√3 t)。
   求平面 PCD 的法向量：面 PCD 内 CD = D−C = (0,1,0)，CP = P−C = (−1,0,√3)。设 n=(a,b,c)，由 n·CD=0、n·CP=0 → b=0, −a+√3c=0 → 取 c=1：n=(√3,0,1)。
   线面角：sinθ = |cos⟨EF,n⟩| = |EF·n|/(|EF|·|n|)。
   EF·n = (1/2−t)·√3 + (−1/2)·0 + (√3/2−√3 t)·1 = √3/2−√3t + √3/2−√3t = √3(1−2t)。
   |EF| = √((1/2−t)²+(−1/2)²+(√3/2−√3t)²) = √((1/4−t+t²) + 1/4 + (3/4−3t+3t²)) = √(4t²−4t+5/4)。|n| = 2。
   方程：√3|1−2t| / (2√(4t²−4t+5/4)) = √39/13 → 平方：3(1−2t)²/(4(4t²−4t+5/4)) = 39/169。
   化简：3(1−4t+4t²)·169 = 39·4·(4t²−4t+5/4) → 507(1−4t+4t²) = 156(4t²−4t+5/4) → 507−2028t+2028t² = 624t²−624t+195 → 1404t²−1404t+312=0 → 除以 156：9t²−9t+2=0 → (3t−1)(3t−2)=0 → **t=1/3 或 t=2/3**（均满足 0<t<1）。
   对应 PF/BF = t/(1−t)：t=1/3 → **(1/3)/(2/3) = 1/2**；t=2/3 → **(2/3)/(1/3) = 2**。
4. **结论**：**（1）四点共面（2）存在，PF/BF = 1/2 或 2**。

**动图联动**：四棱锥可旋转；第（1）问高亮 O、D、E、F；第（2）问建立坐标系，动点 F 沿 PB 运动，实时显示 sinθ、PF/BF；学生拖 F 观察角如何达到 √39/13。

**设计意图**：①空间向量“建系-坐标-法向量-夹角”完整流程；②动点参数化与方程求解；③“存在性→构造方程→检验”的答题规范。

### 环节七 方法总结与作业（约 3 分钟）
**小结**：
```
解析几何：
  最值 → 定义转化 + 三角不等式（题1）
  轨迹 → 位置关系 → 定义（题2）
  定点 → 设线联立韦达 + 检验（题3）
立体几何：
  截面 → 平行面截性 + 临界分析（题4）
  空间角 → 建系 + 法向量 + 参数方程（题5）
```
